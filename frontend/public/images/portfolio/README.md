# Public portfolio previews

These static screenshots show the existing application interfaces at 1440 by
900 pixels. They contain synthetic demonstration data only. They do not grant
access to the applications or their APIs.

- `fleet-vor-hub.png`: Fleet Issue Hub, using the authenticated UI regression
  fixture from `frontend/e2e/fleet-hub-authenticated.spec.ts`, with a synthetic
  van and example messages attributed to demonstration teams. No email is sent.
- `workforce-intelligence.png`: People Voice published findings, using the
  project router's prepared `INTERVIEW_SEED` report from a disposable SQLite
  database. The report is a seeded demonstration, not evidence of a live AI run.

Captured on 21 November 2026 with Chromium against localhost. Browser requests
used local test fixtures. No production session, private profile, employee data,
provider credential or live API response was used.
