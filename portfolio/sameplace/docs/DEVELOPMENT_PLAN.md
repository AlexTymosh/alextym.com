# Development plan

The [session ledger](../SESSION_NOTES.md#5-sequential-pr-roadmap-and-logical-commits) is the detailed authoritative implementation sequence: 10 PRs, 46 planned logical commits. Do not duplicate or silently diverge from it. SP01 ships registration, disabled entrypoints, locale and activity metadata contracts, freeze guard, build integration and documentation. SP02 builds private rooms, ownership, membership and room-scoped invitation redemption; it must not weaken global Lab policy. SP03 establishes realtime/social features. SP04 adds interiors/music. SP05 adds independent Room Voice & Video and local audio mixer. SP06 creates activity lifecycle and SDK. SP07 extracts a separate Preferans engine from the pinned tree.  SP08 bots, SP09 approved Domino module, SP10 release gates.

Each candidate is based on the actual latest main, delivered as a ZIP with exact inputs and tests; local CI and merge confirmation are required before the next PR. If a stage grows beyond a reviewable boundary, record the reason and split only at a working checkpoint. No artificial commits, no unrelated refactoring, no production activation, no paid configuration. Preserve all historical notes; keep detailed English documentation current with each change.
