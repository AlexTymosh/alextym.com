# ADR 0004 — Single-worker, room-scoped realtime with durable social storage

- Status: accepted for SP03 candidate, release subject to evidence.
- Context: Room Core is durable; friends must meet without Owner and private game modules must not own room transport. GBP 0 prohibits introducing a paid broker or media service. Legacy PR22 removed idle HTTP polling. A guest may have only room membership.
- Decision: project-local composed router, bounded process-local admission/tickets/leases and viewer snapshots; exact origin and independently reverified identity; post-commit invalidation from Room Core; Firestore transactions for durable profile/friends/favourites/chat/inbox. Use one socket per active tab, no distributed capacity claims. Off by default, exact single-worker acknowledgement, no new dependency. Browser uses short ticket only and bounded retries; explicit read-only history when degraded. No global directory, no cross-room room metadata without bilateral friendship/privacy/shared membership. Email/SMS are no-effect consent-checked stubs. Meeting/location intents and last-seen memory are ephemeral; room/score state will remain durable.
- Alternatives: repeated HTTP polling wastes reads, direct browser Firestore weakens existing deny-all and exposes domain data, distributed broker requires verified budget/operations and is unnecessary for initial friends-only workload. A per-game socket would violate room-first design.
- Consequences: restart loses meeting presence, not durable data; limits and immediate invalidation are one-process only, periodic reauth still required. Room archive currently closes presence; SP05 must integrate safe active-game pause. Chat uses bounded small-room aggregate with 30-day expiry and hard cap, not unbounded messaging service. Friend presence/inbox outside rooms is on-demand; no global website monitoring. Retry admission is not FIFO. Measure free quota, full locked CI, Emulator and multi-client actual browsers before activation. Later multi-worker expansion requires a separate decision and distributed admission/revocation, not a change of flag.
