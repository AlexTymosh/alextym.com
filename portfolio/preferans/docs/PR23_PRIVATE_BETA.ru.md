# PR23 — интерфейс закрытой беты

- Игровой маршрут не показывает общий футер сайта; другие маршруты не изменены.
- Красная точка мигает при подтверждённой связи, при известной потере связи рамка красная. В HTTP fallback состояние других участников неизвестно и не выдаётся за потерю связи.
- Жёлтая рамка заполняется от времени активности, ограничена 180 секундами. Это визуальный индикатор, не команда счётчика, не источник штрафа. Действующие серверные паузы/счётчик сохраняются.
- Прозрачность 0–75% изменяет только цвет поверхности и сохраняется в локальном профиле браузера. Старое значение `glass` поддерживается как зелёное сукно с прозрачностью по умолчанию 50%; новые настройки его не предлагают.
- В распасах первая открытая карта прикупа показывается рядом с рубашкой второй. Сервер не раскрывает скрытую карту до установленного правилами момента.
- Адресные предложения выбросить листик сняты с API и UI. Добровольный выход с подтверждением доступен в локальном и общем просмотре пульки. Незакрытый счёт не пересчитывается. Старые итоги и события сохраняются, старые предложения не исполняются.
- В лобби имена относятся к занятым местам, не обязательно к активным соединениям. Отдельно показаны известные подключённые игроки. Выборка сохраняет прежние границы доступа и бюджет не более 30 дополнительных чтений профилей на ручной запрос каталога; нет новых фоновых запросов. История загружается при открытии лобби без автоматического опроса. Возраст комнаты обновляется локально раз в минуту.
- Магнитофон справа, ширина увеличена примерно на 30% с адаптивными пределами.
- Меню закрывается при клике вне него или Escape, включая срочный раздел; его можно открыть вручную повторно.
- Статус продукта — закрытая бета, не гарантия завершения приёмки.

## Приёмка

Проверить три клиента, offline/reconnect, 180-секундную рамку, первый ход распасов, обе пульки, отказ старых команд, доступность меню клавиатурой и на мобильном экране, ссылку в буфере и отсутствие новых периодических Firestore-запросов. Проверить CI, Firebase Emulator и production realtime отдельно. Не считать изолированные тесты подтверждением визуальной или production-приёмки.
