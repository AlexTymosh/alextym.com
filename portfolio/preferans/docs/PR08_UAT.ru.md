# PR 8 — обязательная проверка трёх независимых браузеров

Нельзя включать `PREFERANS_MEDIA_ENABLED` в production по одному локальному unit/e2e-тесту. Выполнить **три аккаунта** на **трёх отдельных устройствах и как минимум двух разных сетях**; задокументировать браузеры и версии.

1. Пройти `task repo:check`, `task backend:check`, `task frontend:check`, `task ci`, все пять GitHub Actions jobs, Docker build. Отдельно запустить `test_media.py` и `frontend/e2e/preferans-media.ru.spec.ts`.
2. Без `PREFERANS_MEDIA_ENABLED=true` backend и Next.js должны отвечать 404 для медиаканала, но игровая комната продолжает работать. Без project grant — 403, без сессии — 401, не-член комнаты — 404. Owner вне трёх мест не читает SDP/ICE.
3. У трёх разных игроков активировать микрофоны/камеры независимо, проверить двухстороннее слышно/видно A↔B, B↔C, A↔C; переместить вкладку в background, обновить и восстановить после сети. Протестировать отдельно с отключёнными микрофоном и камерой.
4. Тест под строгим NAT/корпоративной сетью должен **честно провалить медиа**, не приводя к сломанному ходу/рейтингу. Зафиксировать, нужен ли TURN (строго £0 не гарантирует его).
5. A запрашивает запись, B соглашается, C не отвечает — запись не начинается. C отказывает — нельзя включить. Новое предложение: все трое соглашаются — только инициатор A получает `record_start`; B/C не могут запустить запись.
6. Во время записи каждый видит красный индикатор. Один из B/C отзывает согласие — запись A останавливается. Измерить задержку между нажатием и реальным `MediaRecorder.stop`, включая отказ связи/пропуск poll; **если задержка не отвечает требованию немедленной остановки, блокировать релиз**.
7. Проверить файл: локально скачивается только у A, содержит звук A+B+C, кадры разрешённых камер и **только открытый стол**; никогда не должен содержать закрытые карты, снос, закрытый прикуп, чужие окна браузера. Проиграть файл стандартным плеером, проверить codec/MIME и Safari.
8. Выключить камеру в ходе разговора, включить обратно, проверить повторную ICE negotiation без утечки прошлых потоков. Завершить игру без медиадоступа.
9. Проверить Firestore: клиентский deny-all, документы `media/current`, адресные сигналы и задержку их физического удаления, размер документа при 64 сигналах, отсутствие любых файлов/медиабайтов в Firestore, Storage, Vercel, Render.
10. Измерить фактическое число Firestore reads/writes в 2-часовой трёхсторонней сессии, проверить бюджет, ограничения бесплатного уровня и план очистки `media_operations`.

**Критические блокеры перед production:** гарантированная остановка записи при отзыве, тест на реальных устройствах, стоимость signalling/presence и очистка TTL-документов. Эти блокеры нельзя закрыть только зелёным CI.
