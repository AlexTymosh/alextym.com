7. Убедиться, что API, audit и browser network response **не содержат** `GameState`, чужих карт, скрытого сноса, Firebase UID и ключей.
8. В тестах: triple-tie без золота; два лучших → два золота; два худших → два вторых места; гипотетический sheet discard → два золота соперникам и два направленных голых. Самого sheet-discard действия в PR 7 пока нет.
