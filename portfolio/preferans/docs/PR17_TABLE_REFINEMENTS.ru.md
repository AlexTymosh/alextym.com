# PR17 — уточнения игрового стола

Основа: PR #288, main e108b3bc1eba84585c9edb67a1e9fa3bca3e1ca2. Один PR.

- Свёрнутая панель сохраняет ширину; настройки и управление открываются отдельной панелью. Правила и история — отдельные вкладки. Рубашки карт — в настройках, полноэкранный режим — в заголовке.
- FAQ: вопросы, примеры и таблицы из HOUSE_RULES.ru.md и подтверждённые решения HOUSE_RULES_DECISIONS.ru.md. Снимок исходного Markdown сверяется регрессионным тестом. Для обновления правил выполни `node portfolio/preferans/scripts/sync-rules-faq.mjs`; правила комнаты могут отличаться числовыми параметрами.
- Имена над видеоокнами, индикатор связи без текста, буква D на сдающем, обвод активного игрока, часы, речевые облачка победившей заявки и контракта. Размеры аватарок ориентировочно +56% (1.3 × 1.2), карт +25%, взяток ×2, ограничены размером экрана.
- Последняя взятка — только глобально последняя завершённая взятка. Сервер больше не передаёт массив последних взяток отдельных игроков. Закрытые связки выложены попеременно вертикально и горизонтально; только последняя связка победителя доступна для просмотра. При включённом общем пространстве открытие синхронное для всех участников; без него доступен локальный просмотр той же взятки. В FAQ описаны согласованные правила, а не гарантии готовности каждой функции в текущем релизе.
- Пулька уменьшена примерно на 15%, компактная накладка не меняет размеры стола. Существующие серверные записи и правила расчёта неизменны.
- При ошибочном сбросе карты на поле выводится сообщение, серверная команда не отправляется. Открытые руки сортируются по выбранной локальной настройке.
- После подтверждённой транзакции публикующий поток уведомляет текущие WebSocket-соединения комнаты. Событие не содержит карт или состояния, не вызывает чтения Firestore. Период 75 мс и HTTP fallback 4 с сохранены для контроля таймеров, присутствия и восстановления. Ускоряется только доставка уже подтверждённого изменения; фактическое время и тариф не гарантируются без измерений.
