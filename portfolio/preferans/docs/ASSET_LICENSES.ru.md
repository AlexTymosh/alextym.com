# PR11 — графика карт и происхождение

- `frontend/src/atlas-art.ts`: оригинальная программно нарисованная векторная колода 32 карт и одна рубашка, созданная специально для модуля. Русские индексы, симметричные фигуры, традиционные масти и красный диагональный узор. Это стилизация классической атласной колоды, не скан конкретного издания и не точная копия исторических иллюстраций. Владелец может принять или заменить оформление отдельно.
- 33 SVG-изображения формируются из фиксированных путей; на клиенте только кэш по валидным рангу/масти; никакие SVG из пользовательского ввода не исполняются. Приватные рубашки одинаковые и не содержат ID скрытых карт.
- Пиктограмма игрока — собственная простая SVG-геометрия; внешние шрифты, фотографии, CDN, зависимости или коммерческие лицензии не добавлены. Загруженные пользователями изображения профилей отображаются только участникам их комнаты; профильный сервис уже нормализует изображения в WebP. Провайдерские URL не используются в PR11.
- Существующее фоновое изображение `nostalgic-room.webp` не заменяется; сохраняются прежние сведения о его происхождении.
- `table-preview.html` — автономный макет с синтетическими данными. Не устанавливается в репозиторий/публичный сайт; без сетевого доступа или реальных операций. Скриншоты — макет, не production.

## PR13 — общие предметы и звук

- Оригинальная векторная геометрия магнитофона и листа пульки в `SharedRoom.ru.tsx`; не копии товарного изображения.
- `frontend/public/preferans/audio/test-01.wav` и `test-02.wav` — две специально синтезированные тестовые мелодии, 12 секунд, mono PCM 16 kHz. Не являются коммерческими записями или имитацией конкретной песни. Разрешено использовать в данном проекте. Треки статические, публично доступные, не содержат пользовательских данных.
- Замена тестовых звуков на коммерческую музыку требует отдельно проверенных прав и изменения согласованного манифеста длительностей; не добавлять копии из стриминговых подписок.

## PR15 — карты и пулька

`classic-court.ts` и `atlas-art.ts` — оригинальная SVG-отрисовка по визуальным принципам традиционных атласных карт и предоставленным референсам. Не сканы, не заявляется точное воспроизведение исторического набора. Текущая рубашка сохраняется; три новых геометрических варианта отрисованы программно. Ссылки на внешние изображения, коммерческие шрифты, CDN или музыка не добавлены. Пулька — SVG с локальными системными шрифтами; внешний вид рукописного шрифта зависит от устройства. Требуется визуальная приёмка Owner.

## PR16 — атласные карты

Лицевые изображения: Дмитрий Фомин, «Atlasnye playing cards deck», исторические рисунки А. И. Шарлеманя. Источник: https://commons.wikimedia.org/wiki/Category:SVG_Atlasnye_playing_cards . Лицензия CC0 1.0, проверяемая для каждого файла через Commons API при импорте. PNG-превью сохраняются локально, без запросов к Wikimedia во время игры; `frontend/public/preferans/atlas/sources.json` содержит ссылки, лицензию и SHA-256. Рубашки не изменены. Иконка проекта — оригинальный SVG.
