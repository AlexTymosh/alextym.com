## Контракт

Новые действия через существующий защищённый `POST /api/preferans/rooms/{id}/commands`. Idempotency key и expected_version остаются прежними. `args.presentation_version` обязателен для shared actions, `overlay_id`/`break_id` защищают от закрытия чужого нового объекта. Только сидящие участники, никаких изменений хостовой авторизации. Сервер принимает только allow-listed поля; время, раскрытые карты, инициатор и состояние очков определяются сервером.

| Action | Дополнительные args |
|---|---|
| overlay_open | kind: score_sheet / radio / last_trick / widow_replay |
| overlay_close | overlay_id |
| break_start | — |
| break_ready | break_id, ready: boolean |
| music | command: play / pause / stop / next / previous |

Состояние хранится в существующем private/current.controls.presentation, публичная проекция только участникам. Отдельный presentation revision, общий монотонный room version увеличивается при фактическом durable commit для совместимости существующих HTTP/WS CAS, событий и polling. Это осознанное ограничение текущего протокола, а не отдельный источник игрового состояния: domain GameState, score, номер сдачи и счётчик версии ledger не меняются от просмотра/музыки. Не записывать position/heartbeat/громкость. Переходы pause_clock и фактический игровой ход в одной транзакции. Не возвращать private undo snapshots, UID, снос, закрытый прикуп.

## Паузы

- Открытие/замена общего объекта ставит shared_overlay; закрытие снимает только эту причину. Перерыв независим; три явных ready в одном break ID обязательны. Смена epoch или наблюдаемая потеря связи сбрасывает подтверждения консервативно, даже при быстром reconnect; offline seat не может подтвердить. Повторные запросы обрабатываются старым idempotency механизмом.
- Last trick: только при единственной внешней причине shared_overlay разрешается попробовать `play`; сначала apply_command, затем close_after_move. Ошибочная карта, чужой ход, устаревшая версия, undo, break, connection_lost не закрывают объект. Счётчик, окно голосования и next_deal используют остаток через существующий transition. Общий перерыв может существовать одновременно с одним общим объектом.
- New shared actions требуют серверного realtime gate PR10. При выключенном gate старые комнаты используют прежние личные панели. Уже открытый overlay можно закрыть после выключения; активный break не форсировать. Плановый rollback: закрыть overlay и завершить break тремя ready до отключения флага; если отключили с активным break, восстановить прежний realtime gate, подключить всех, подтвердить ready, затем откатывать. Не править Firestore вручную. HTTP fallback при включённом gate использует прежний presence lease; задержка выше. До подтверждения topology/CI/UAT не менять production flags.

## Представление

Листок в клетку с текущими суммами пули, горы, направленных вистов, целью в центре и сектором своего игрока снизу. Это итоговые суммы, не история записей рукой. История/ranking и корректировки с причиной остаются существующими отдельными панелями. Перемещение общих объектов и локальная громкость не меняют score. Последняя взятка — три ранее сыгранные карты и победитель/эффективная масть. Прикуп — только уже раскрытая public widow. Никакой новой передачи скрытых данных.

Оригинальный SVG магнитофона и два собственных WAV по 12 с, см. ASSET_LICENSES. Серверная команда якорит track/playing/offset/changed_at; после окончания трека следующий вычисляется по времени, без отдельной записи. Клиент корректирует позицию локально, часы WS и HTTP используются как приближённая синхронизация. Это тестовый плейлист, не коллекция коммерческих песен. Нужен явный browser gesture; звук optional. Доступность аудио, drift и кэш проверяются на реальных браузерах. Видеозапись исключена. Live media пока в прежнем меню; SDP/ICE, видео возле мест и сокращение signalling polling — срез D.
