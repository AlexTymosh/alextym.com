# PR37 — уточнения игрового интерфейса

- Когда открыты масти, другие доступные уровни приглушены, недоступные сохраняют прежнюю прозрачность. Кнопки мастей на 10% ниже, выровнены по нижнему краю, после группы увеличен отступ. Шрифт БК соответствует числовым/специальным заявкам.
- В подготовке комнаты администратор может скопировать каноническую ссылку с параметром `room`. Текст технического поражения разбит на два абзаца, размер уменьшен на 40%.
- Открытая пулька получает фокус без прокрутки страницы; колесо работает в области листика, включая прокрутку увеличенного изображения. Масштаб окна и правила расчётов неизменны.
- Обычный прикуп соперники видят автоматически до десяти секунд. До первой сыгранной карты повторный просмотр доступен при удержании кнопки или текста; при отпускании, отмене касания и потере фокуса карты снова закрыты. После первого хода контуры исчезают. Прикуп распасов сохраняет отдельные правила. Старый серверный запрос повторного просмотра обычного прикупа после первого хода отклоняется.
- Снос показывается только заказчику в существующих двух позициях возле руки. Соперники при общем просмотре получают только сообщение; серверная модель и приватная проекция не меняются. При объявлении игры кнопки размещаются рядом со сносом.
- Шутка «спрятать надежно»: первая анимация использует обычные авторизованные элементы руки — собственные лица и чужие рубашки. До завершения первой визуальной раздачи прикуп обозначен обычными рубашками; затем они исчезают (только визуальный эффект). После завершения обычной раздачи появляется жалоба (2 с), затем «Вот они!» (2,8 с), затем повторная раздача. Границы 3900/5900/8700/10100/14000 мс. Серверная блокировка команд синхронизирована с клиентом, исходная колода не изменяется. При возвращении на страницу анимация учитывает прошедшее время.
- Рамка активности тоньше на 15%; надпись первой руки выровнена слева, если очередь принадлежит локальному игроку — «Ход за тобой».

## Приёмка

Проверить три реальных клиента на ноутбуке и большом мониторе, мышь/касание/клавиатуру для прикупа, закрытие после первой карты, отсутствие чужих карт в данных, масштаб и прокрутку пульки, оба этапа юморной раздачи и отсутствие преждевременных игровых команд. Проверить CI и сборку production. Новые периодические запросы или тарифы не вводятся.
